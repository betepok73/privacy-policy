1C Invoices

1C Invoices — настольное приложение, которое отправляет счета (invoice) вашим клиентам от вашего имени через электронную почту Gmail. Приложение создано для бухгалтеров и предпринимателей, которые выставляют счета из 1С и хотят отправлять их клиентам по электронной почте автоматически, без ручного копирования писем.

Как это работает

  • Приложение формирует письмо со счётом и вложенным PDF-файлом.
  • Через Gmail API оно отправляет письмо с вашего адреса Gmail получателю (вашему клиенту).
  • Письмо попадает в папку «Отправленные» вашего аккаунта Gmail — вы видите каждую отправку.

Какие данные и сервисы Google используются

  • Сервис: Gmail API (api.gmail.com).
  • Запрашиваемый объём доступа: https://www.googleapis.com/auth/gmail.compose — только создание и отправка писем.
  • Приложение не читает вашу переписку, не открывает чужие письма, не использует Google Диск, Контакты или YouTube.
  • Приложение не собирает данные пользователей для рекламы и не продаёт данные третьим лицам.
